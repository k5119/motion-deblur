# 직접 구현 코어 검증

## 구현

- **합성** — 기존 선형 PSF의 합을 1로 정규화한다. 0°는 오른쪽,
  각도는 시계 방향의 180° 주기다. 잡음 표준편차가 양수이면
  uint8 BGR을 [0, 1] float32로 바꾸고 반사 경계 컨볼루션, 시드 기반
  독립 가우시안 잡음, 클리핑·양자화 순서로 처리한다. 0에서는 기존
  uint8 컨볼루션을 호출한다.
- **PSF → OTF** — 홀수 커널을 FFT 크기로 영 패딩하고 중심을 (0, 0)으로
  순환 이동한 뒤 실수 FFT를 계산한다. 단위합 PSF의 DC 응답은 1이다.
  비대칭 PSF와 영상 모서리의 임펄스로 위치와 위상을 검증했다.
- **Wiener** — 기존 역필터 H*G / (|H|² + K)를 유지한다. 기본 경계
  `taper`와 float64 계산은 기존 출력과 일치한다.
- **Richardson–Lucy** — 초기 추정은 0.5로 채운다. 각 채널에서
  x ← x · Aᵀ(y / max(Ax, ε))를 반복한다. A는 패딩된 작업 배열의
  순환 컨볼루션이고, Aᵀ는 켤레 OTF로 계산한다. 단위합 PSF에서는
  Aᵀ1=1이다. ε=10⁻⁶으로 0 나누기를 막고 수치 오차로 생긴 음수
  보정값은 0으로 제한한다. 비유한 반복값은 오류로 처리한다. 마지막에
  원래 영역을 잘라 uint8로 변환한다.
- **경계** — `wrap`은 패딩 없는 순환 컨볼루션, `reflect`는 반사 패딩
  후 복원과 크롭, `taper`는 같은 패딩의 바깥 부분을 채널 평균 쪽으로
  감쇠한 뒤 복원한다. taper는 원본 영역 픽셀을 직접 바꾸지 않는다.
  반사·감쇠는 바깥 영역을 근사하므로 경계 개선을 보장하지 않는다.

## Linux CPU 실험

scikit-image camera를 256×256으로 줄인 뒤 45°·15px PSF를 적용했다.
합성은 두 잡음 조건(σ=0, 0.01)에 시드 702를 기록했고, Wiener는
K=0.005를 사용했다. 같은 합성 입력으로 세 경계와 RL 10·20·40회를
실행했다. 표의 시간은 단회 처리 시간이며, 그래프 작성과 이미지
저장 시간은 제외한다.

| σ | 방법·경계 | PSNR(dB) | SSIM | 시간(ms) |
| ---: | --- | ---: | ---: | ---: |
| 0 | 합성 입력 | 22.486 | 0.6748 | — |
| 0 | Wiener wrap | 20.037 | 0.5791 | 16.2 |
| 0 | Wiener reflect | 23.159 | 0.6324 | 5.2 |
| 0 | Wiener taper | 27.077 | 0.7741 | 5.7 |
| 0 | RL 20 taper | 25.543 | 0.7727 | 91.8 |
| 0 | RL 40 taper | 26.442 | 0.7933 | 173.2 |
| 0.01 | 합성 입력 | 22.411 | 0.6290 | — |
| 0.01 | Wiener taper | 24.061 | 0.4478 | 5.7 |
| 0.01 | RL 10 taper | 24.553 | 0.7125 | 41.8 |
| 0.01 | RL 20 taper | 25.255 | 0.6987 | 80.7 |
| 0.01 | RL 40 taper | 25.634 | 0.6466 | 164.6 |

잡음이 있는 camera에서 RL을 10회에서 40회로 늘리면 PSNR은 상승했지만
SSIM은 하락했다. 사진 내용과 PSF에 따라 적절한 반복 횟수는 달라진다.
컬러 chelsea(256×170, σ=0.01)에서는 블러 입력이 25.909dB/0.6564,
Wiener taper가 25.410dB/0.5524, RL 20 taper가 28.462dB/0.7630이었다.
이 조건에서는 기본 Wiener가 합성 입력보다 두 지표 모두 낮았다.
이 단계에서는 채널별 BGR 복원을 검증했다. Y 채널 방식과 선택적 후처리는
품질 고찰을 위한 후속 항목이다. 실제 촬영 사진, Windows와 CUDA는
이번 코어 실험에서 미검증이다.
