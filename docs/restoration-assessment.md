# 복원 필요성 판단 기준 및 검증

## 판단 순서

판단은 종횡비를 유지하면서 긴 변을 512px로 제한한 영상의 지표를 사용한다.
작은 입력은 그대로 분석한다. 원본 분석은 별도로 출력하고, `--max-size`는
복원 영상 크기만 결정한다. 모든 판단 기준은 `motion_blur/decision.py`의
상수로 설정할 수 있다.

1. 평균 밝기가 50~205 밖이거나 어두운 픽셀(0~50) 또는 밝은 픽셀(205~255)의
   비율이 50% 이상이면 판단 보류다. 평가는 한쪽 노출 구간이 절반을
   차지하는 어두운 점 패턴과 극단 노출 대조군에서 선명도 해석을 유보한다.
2. 히스토그램으로 구한 명암값의 모집단 표준편차가 8 미만이면 판단 보류다.
   균일한 회색과 낮은 대비의 선분 대조군에서 경계가 부족하거나 약할 때
   분산을 해석하지 않도록 선택한 기준이다.
3. Laplacian 분산이 300 이하이고 FFT가 방향 후보와 점수 0.30 이상을
   반환하면 복원 권장이다. 300은 정상 노출에서 여러 합성 PSF의
   낮은 분산을 포함하는 기준이다. 0.30은 후보 반환 기준인 0.20보다
   높은 보조 기준이며, 검증에서 경계 부근의 방향 후보 일부를 보류시켰다.
4. Laplacian 분산이 1,000 이상이고 FFT 방향 후보가 없으면 복원 불필요다.
   이 높은 기준은 일부 선명한 대조군에서 관측된 분산을 바탕으로 했다.
   보정 필요성을 평가할 때 높은 선명도와 앞선 노출·대비 조건도 필요하다.
5. 그 외에는 판단 보류다. 예를 들어 선명도가 낮고 FFT 후보가 없거나,
   선명도가 높은데 방향 후보도 있으면 보류한다.

FFT 점수는 주파수 방향 특징의 강도와 대역 간 일관성을 요약한 값이다.
실험에서 사용한 임계값은 잠정 휴리스틱이며 일반화 성능은 검증하지 않았다.
짧은 변과 촬영 조건은 여전히 달라질 수 있고, 축소하면 약한 블러가
희석될 수 있다. 판단 결과는 복원 실행과 모델 입력을 제어하지 않는다.

## 검증 결과

기존 FFT 검증의 입자, 복합 질감, 원 패턴, OpenCV fruits·graf1을 재사용했다.
각각 6개 각도 × 3개 길이로 합성한 모션 블러에 대한 결과다.

| 입력 | 적용 전 판단 | PSF 후 복원 권장 | PSF 후 판단 보류 | PSF 후 복원 불필요 |
| --- | --- | ---: | ---: | ---: |
| 입자 | 복원 불필요 | 0 | 18 | 0 |
| 복합 질감 | 복원 불필요 | 18 | 0 | 0 |
| 어두운 원 패턴 | 판단 보류 | 0 | 18 | 0 |
| fruits | 판단 보류 | 15 | 3 | 0 |
| graf1 | 복원 불필요 | 18 | 0 | 0 |
| 합계 | | 51 | 39 | 0 |

균일한 회색, 값 12·240의 균일 영상, 선명한 수평 선분과 세로 줄무늬,
등방성 Gaussian 흐림은 판단 보류였다. 대표적인 오판도 재현했다.

- 수평 선분의 대비를 20%로 줄이고 세로 방향으로 −30~+30의 선형 밝기
  구배를 더하자 모션 블러를 적용하지 않았는데 복원 권장이 나왔다.
  Laplacian 분산 116.75와 FFT 점수 0.382가 두 기준을 충족했다.
- graf1을 4032×3024로 확대해 9px·45° PSF를 적용한 경우, 512×384 판단
  영상에서 Laplacian 분산 1068.55와 FFT 점수 0.043이 나와 복원
  불필요로 오판했다. 같은 조건의 21px PSF에서는 판단 보류였다.

다음 명령으로 합성 대조군 테스트를 다시 실행할 수 있다.

```powershell
python -m unittest -v tests.test_decision
```
