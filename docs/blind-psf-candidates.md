# 블라인드 PSF 후보 평가

## 선택과 평가의 분리

`search_psf(observed, ...)`는 흐린 입력으로만 후보와 결과를 생성한다.
FFT와 그래디언트 추정 축 및 각각 ±8° 축에서 켑스트럼 국소 골을
최대 세 개 사전 선정하고, 분석 크기의 끝점 간 거리 L−1을 기존 환산
함수로 입력 픽셀에 환산한다. 단일 FFT 후보가 유효하면 비교 기준과
후보군에 함께 둔다. 방향 근거가 없으면 복원을 보류한다.

선택 점수는 정규화된 BGR에서 아래 세 값의 합이다. 모든 후보에 같은 K
또는 같은 RL 반복 횟수를 사용한다.

| 항 | 계산 |
| --- | --- |
| 재블러 MAE | 복원 결과를 후보 PSF로 다시 흐리게 했을 때 관측 입력과의 평균 절대 차 |
| 평탄부 고주파 | 관측 입력의 7×7 범위가 채널 전체에서 0.06 미만인 위치에서 복원값과 Gaussian 저역 통과값의 평균 절대 차 |
| 오버슈트 | 복원값이 관측 입력의 채널별 7×7 최소·최대 범위를 넘는 정도의 평균 |

점수 = 재블러 MAE + 2 × 평탄부 고주파 + 2 × 오버슈트. 최솟값을
고르며, 동률이면 먼저 생성된 후보를 유지한다. 평탄 영역이 없으면 해당
항은 0이다. 고주파와 오버슈트는 노이즈와 링잉의 대리 지표이며 선명한
구조에서도 커진다. 짧은 PSF나 부드러운 결과에 유리할 수 있다.

선택 확정 후의 평가에서만 참조 영상을 사용한다. 각 후보의 참조 점수를
기록하기 위해 필요한 경우 다시 복원하며, 이 점수로 순위를 바꾸지
않는다. 합성에서만 정답 각도·길이 오차를 계산한다. 재블러 점수와
참조 품질의 일치 여부, 입력이나 단일 FFT보다 낮은 PSNR, 다른 후보가
더 좋은 사례를 각각 기록한다.

## 실제 실행과 한계

Linux CPU에서 공개 샘플 camera·chelsea·astronaut에
0°·9px·σ=0, 30°·15px·σ=0.01, 135°·35px·σ=0.01을 합성했다.
난수 시드는 702다. 최대 256px에서 Wiener로 후보를 채점하고 같은
선택 PSF로 RL도 복원했다. NAFNet은 기존 가중치로 실행했다.

- 선택 Wiener는 9조건 중 6조건에서 입력보다 PSNR이 낮았으며, 6조건에서
  다른 후보가 선택 후보보다 PSNR이 높았다. 같은 PSF를 적용한 RL에서는
  5조건에서 입력보다 PSNR이 낮았다.
- 단일 FFT PSF가 반환된 6조건 중 3조건에서는 두 복원 모두 후보 선택
  결과의 PSNR이 단일 FFT보다 낮았다. 긴 블러 조건에서는 단일 FFT가
  보류된 경우에도 탐색이 후보를 반환했지만, 예를 들어 camera의 35px
  블러에 7px를 선택했다. 보류를 줄인 횟수를 성공률로 해석할 수 없다.
- 참조 없는 NAFNet 공식 흐림 예제는 비교 이미지만 생성했다.
  GoPro 및 RealBlur-J 경로와 CSV 형식은 두 개의 합성 모의 쌍으로 검증했다.
  실제 데이터셋 파일과 사용자 촬영 사진, Windows·CUDA는 미검증이다.

256px Wiener 채점의 9개 합성 조건 평균은 다음과 같다. 단일 FFT는
6개 조건에서만 복원됐으므로 아래 9조건 평균과 직접 대조하지 않는다.

| 방법 | PSNR(dB) | SSIM |
| --- | ---: | ---: |
| 합성 입력 | 22.34 | 0.6209 |
| 후보 선택 Wiener | 23.42 | 0.4812 |
| 동일 선택 PSF의 RL | 23.40 | 0.6178 |
| NAFNet | 27.07 | 0.7782 |

별도 192px·RL 8회 채점 실험에서는 RL 결과가 9조건 중 4조건에서
입력보다 낮은 PSNR을 보였고 7조건에서 다른 후보의 PSNR이 더 높았다.
두 실험은 해상도와 반복 설정이 달라 채점기별 우열을 비교하는 근거로
사용하지 않는다. 후보 점수는 기존 단독 복원의 기본 경로에 적용하지
않았다.
