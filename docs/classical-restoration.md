# 선형 모션 블러와 Wiener 복원

## 합성과 복원

각도 θ의 직선에서 아화소 위치를 균등 표본화한다. 각 표본을 네 인접
화소에 양선형 가중치로 배분해 PSF `h`를 만들고, 커널 계수의 합을 1로
정규화한다. 길이 `L`은 픽셀 단위이며, 표본의 끝점 간 거리는 `L−1`이다.
선형 축은 180° 주기를 갖는다. 합성은 2차원 컨볼루션
`g = h * f`를 BGR 채널별로 계산하며, 영상 끝은 반사 경계를 사용한다.
`psf.json`에 각도, 길이, 해상도와 PSF 구현 버전을 저장한다.

복원에서는 블러를 `G = HF + N`으로 놓는다. `G`는 관측 영상, `H`는
PSF의 전달 함수, `F`는 원본, `N`은 잡음의 주파수 표현이다.
중앙이 원점인 PSF를 영상과 같은 FFT 크기에 배치하고 커널 중심을
배열의 인덱스 (0, 0)으로 이동한다. Wiener 근사는 다음과 같다.

```text
F_est = conjugate(H) · G / (|H|² + K)
```

양수 `K`는 주파수별 잡음 대 신호 전력비를 상수로 근사하는 정규화 값이다.
`K`가 작을수록 약한 주파수 성분을 더 강하게 복원하지만 잡음과 링잉을
증폭할 수 있다. 블러 영상은 반사 패딩하고 바깥 패딩만 채널 평균으로
감쇠해 FFT에서 양쪽 끝이 맞닿을 때의 불연속을 줄인다. 역 FFT 뒤에는
원본 영역을 잘라내고 반올림 및 클리핑해 uint8 PNG로 저장한다.

정답 PSF 복원은 합성에 사용한 각도와 길이를 재사용한다. 추정 PSF
복원은 기존 FFT 분석기의 방향 후보와 사용자가 지정한 길이로 커널을
만든다. 방향 후보가 없으면 단독 명령은 PNG 없이 종료 코드 1을 반환하고,
비교 실험은 다른 결과를 저장하면서 `metrics.json`에 생략 상태를 남긴다.

## 화질 비교

PSNR은 8비트 BGR 전체의 평균 제곱 오차 `MSE`를 이용해
`10 log10(255² / MSE)`로 계산한다. 동일 영상의 PSNR은 무한대이며 JSON에서는
`"inf"`로 기록한다. SSIM은 채널별 11×11 Gaussian 윈도우(σ=1.5)의 국소 평균,
분산, 공분산을 사용하고 유효 영역과 채널에 걸쳐 평균한다. 입력이
11px보다 작으면 짧은 변에 맞춰 홀수 윈도우를 선택한다. 정답 원본의
해상도와 결과 해상도가 같아야 지표를 계산한다.

```text
SSIM_local = ((2 μx μy + C1) (2 σxy + C2))
           / ((μx² + μy² + C1) (σx² + σy² + C2))
C1 = (0.01 · 255)², C2 = (0.03 · 255)²
```

### CPU 실행 예시

OpenCV 샘플 fruits.jpg를 합성 전에 384×360으로 축소했다. 합성에는
45°·15px, 추정 복원에는 사용자 지정 길이 15px를 사용했다. FFT 방향
후보는 44.87°였으며 두 Wiener 복원의 `K`는 0.005였다.
[OpenCV 샘플 이미지](https://raw.githubusercontent.com/opencv/opencv/4.x/samples/data/fruits.jpg)

| 원본과 비교한 영상 | PSNR(dB) | SSIM |
| --- | ---: | ---: |
| 합성 블러 | 26.132 | 0.6730 |
| 정답 PSF Wiener | 30.486 | 0.8585 |
| 추정 PSF Wiener | 30.487 | 0.8585 |
| NAFNet | 29.884 | 0.8366 |

Linux CPU에서 실험했다. 이 한 사례의 점수 차이는 복원 방식의 일반적
성능 순위를 입증하지 않는다. 블러가 위치에 따라 달라지거나 추정
각도·길이가 실제 PSF와 다르면 복원 품질이 떨어질 수 있다. 감쇠와
패딩은 경계 아티팩트를 줄이지만 강한 복원에서 링잉이 남을 수 있다.
균일 영상에서 방향 추정 생략을 확인했다. 이번 변경의 Windows 및
실제 CUDA 실행은 미검증이다.
