# FFT 모션 방향 검증

프로젝트 루트에서 아래 명령을 실행하면 각 사례의 실제 각도, 추정 각도,
각도 오차와 방향성 점수가 CSV로 출력된다. `--output-dir results/fft-images`를
추가하면 검증 입력도 PNG로 저장된다.

```powershell
python -m tests.validate_motion_direction --image "fruits.jpg" --image "graf1.png"
```

grain은 고정 시드의 입자 질감, multiscale은 입자와 저주파 밝기 변화,
dots는 다양한 크기의 원 질감이다. 추가 사진은 OpenCV 예제
[fruits.jpg](https://raw.githubusercontent.com/opencv/opencv/4.x/samples/data/fruits.jpg)와
[graf1.png](https://raw.githubusercontent.com/opencv/opencv/4.x/samples/data/graf1.png)이다.
이 사진들의 촬영 시 블러 상태는 별도로 측정하지 않았다. 검증 스크립트는 정규화된
직선 PSF를 아화소 좌표에서 만들어 원본에 적용한다.

오차는 `abs((추정값 - 적용값 + 90) % 180 - 90)`으로 계산한다. 예를 들어
0°와 179.86°의 축 차이는 0.14°다. 아래 수치는 Linux, Python 3.11.9,
NumPy 2.4.6, OpenCV 4.14.0에서 얻었다.

## 대조군과 실패 사례

| 입력 | 추정 축 | 방향성 점수 |
| --- | ---: | ---: |
| 선명한 grain, multiscale, dots | 모두 추정 불가 | 0.002~0.007 |
| PSF 적용 전 fruits, graf1 | 모두 추정 불가 | 0.138, 0.038 |
| 균일한 회색 | 추정 불가 | 0.000 |
| 선명한 세로 줄무늬 | 추정 불가 | 0.095 |
| 세로 줄무늬에 15px, 90° PSF 적용 | 추정 불가 | 0.095 |
| 블러를 적용하지 않은 수평 선분 패턴 | 0.19° | 0.585 |

주 비교군 90건은 모두 후보를 반환했다. 적용값과의 최대 축 오차는
5.26°였으며 후보 점수의 최솟값은 0.279였다. 대조군 중 수평 선분을
제외한 최고 점수는 0.138이었다. 반환 기준 0.20은 이 두 관측값 사이에서
정했다. 수평 선분의 오탐은 이 기준으로도 남으며 검증 데이터로 선정한
기준의 일반화 성능은 측정하지 않았다.

세로 줄무늬는 줄과 평행하게 이동해도 픽셀값이 그대로여서 이 방식으로는
방향을 복원할 근거가 없다. 글자, 에지, 반복 구조는 강한 방향성을 만들 수
있고, 약한 블러, 여러 이동 방향, 공간적으로 다른 블러, 노이즈는 응답을
약하게 하거나 다른 축을 유도할 수 있다. 균일하거나 짧은 변이 64px 미만인
입력은 추정 불가를 반환한다. 점수는 방향 특징의 크기와 대역 간 일관성을
요약한 값이며, 모션 블러의 확률이나 실사진 각도 정확도를 뜻하지 않는다.
