# PSF 추정 검증

## 방식과 단위

기존 FFT 방향 분석을 변경하지 않고 기본값으로 사용했다. 대조군인
그래디언트 에너지 방식은 가우시안 평활화 뒤 Sobel 구조 텐서의 작은
고유값에 대응하는 축을 취한다. 고유값 차이를 합으로 나눈 이방성이
0.20 미만이면 방향을 보류한다. FFT와 그래디언트의 점수는 각 방법의
방향 특성 지표이며 확률이나 서로 직접 비교 가능한 척도가 아니다.

길이는 선택한 방향 주위 ±5°의 로그 크기 켑스트럼을 표본화하고,
수직 방향 표본으로 공통 바닥을 덜어낸 뒤 국소 음의 골을 찾는다.
후보는 분석 해상도에서 최대 7~39px이며, 짧은 변에 따라 상한을
낮춘다. 후보 점수는 국소 대비의 중앙값과 MAD를 사용한 잠정적인
상대 점수다. 3 미만이면 길이를 보류한다. 높은 점수라도 어떤
블러가 실제 존재하는지 보증하지 않는다.

PSF의 정의에서 실제 끝점 간 거리는 L−1이다. 분석 축의 양 성분에
각각 원본/분석 너비·높이 비율을 곱하고, 벡터 길이에 1을 더해
원본 PSF 길이를 얻는다. 최종 복원 때만 정수 픽셀로 반올림한다.
1024×733의 45°·31px 합성 사례는 512×366에서 **16px**, 원본
환산 **31.02px**, 축 **45.28°**를 반환했다. 512px로 줄이면 짧은
블러의 주파수 신호가 약해질 수 있다.

## 공개 합성 실험

camera, chelsea, astronaut에 0°·9px, 30°·15px, 45°·21px,
90°·21px, 135°·35px를 적용했다. 잡음 σ=0/0.01, 시드 702로
총 30조건을 만들었다. 각도 오차는 180° 주기의 최소 축 차이이고,
길이 오차는 복원 영상의 정수 픽셀 단위다.

| 방법 | 방향 반환 | PSF 완성 | 방향 MAE | 길이 MAE |
| --- | ---: | ---: | ---: | ---: |
| FFT | 30/30 | 29/30 | 1.70° | 1.45px |
| 그래디언트 | 26/30 | 25/30 | 4.85° | 8.52px |

오차 평균은 각각 해당 값을 반환한 조건에서만 계산했다. 선명한
세로 줄무늬에서 FFT는 보류했지만, 그래디언트는 점수 1.0과 90°를
반환했다. 선명한 수평 선분에서는 두 방식 모두 방향과 짧은 길이를
반환했다. camera의 σ=0.01, 135°·35px에서는 FFT 길이가 7px로
틀렸고 Wiener PSNR이 21.25dB에서 20.08dB로 낮아졌다.
이번 공개 영상 비교를 근거로 FFT 기본값을 유지했다.

양쪽 방법이 PSF를 반환한 동일한 24조건에서만 화질 평균을 비교했다.
Wiener는 K=0.005, RL은 20회, 두 방법 모두 taper 경계를 사용했다.

| PSF | Wiener PSNR / SSIM | RL PSNR / SSIM |
| --- | ---: | ---: |
| 정답 | 26.58 / 0.6501 | 26.67 / 0.7622 |
| FFT | 25.96 / 0.6176 | 26.30 / 0.7439 |
| 그래디언트 | 24.26 / 0.5537 | 24.95 / 0.6891 |

## 참조 없는 흐림 예제

NAFNet 공식 blurry.jpg(1280×720)에서 FFT 30.79°, 그래디언트 17.65°를
얻었다. FFT 길이는 분석 크기 512×288에서 10px, 원본에서
23.5px로, 24px 후보를 두 복원에 적용했다. 이 예제에는 검증된
정답 PSF와 선명 참조가 없어 PSNR·SSIM은 계산하지 않았다.
[NAFNet 공식 예제](https://github.com/megvii-research/NAFNet/blob/main/demo/blurry.jpg)

자동 Wiener(K=0.005)의 결과는 격자무늬와 링잉이 실제
출력에서 두드러졌고, 극값 채널 비율은 입력 0.61%에서 7.62%로
증가했다. 수동 31°·15px와 K=0.015의 Wiener에서 2.05%로
감소했지만 잔여 아티팩트가 남았다. 수동 RL 8회는 자동 RL 20회보다
부드러웠다. 여러 설정을 동시에 바꿨으므로 개선을 한 변수에
귀속하지 않았다. 고주파 증가나 극값 변화는 잡음 증폭의 단서이며
참조 화질을 뜻하지 않는다. 사용자 촬영 원본이 없어 해당 사진의
복원 품질 및 Windows 실행은 미검증이다.
