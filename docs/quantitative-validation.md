# 직접 구현 복원의 정량 검증

## 공통 조건

선명 입력에 기존 선형 PSF를 적용한 뒤 가우시안 잡음을 추가한다. 시드는
702이며 모든 방법에 같은 uint8 BGR 관측 영상과 정규화된 PSF를 사용한다.
PSNR은 BGR 전체 채널의 MSE이며, SSIM은 채널별 11×11 Gaussian
윈도우와 유효 영역 평균을 사용한다. 시간에는 복원과 결과 양자화가
포함되며 모델 로드, PNG 저장, 지표 계산은 제외한다.

| 비교 | 일치시킨 조건 | 남은 차이 |
| --- | --- | --- |
| 직접 Wiener wrap ↔ scikit-image Wiener | 같은 PSF, 채널별 실행, 순환 경계, K=0.005. scikit-image의 정규화 연산자는 항등으로 설정해 분모를 `abs(H)^2+K`로 맞춤 | 내부 FFT 구현. 두 방식 모두 최종 [0,255] 양자화 |
| 직접 RL wrap ↔ scikit-image RL | 같은 PSF, 20회, 채널별 실행, 초기값 0.5, 최종 범위 클리핑 | 직접 방식은 순환 경계·float32·분모 바닥 1e-6. scikit-image는 영 경계·float64·분모에 1e-12를 더하며 경계 수반 연산은 방식이 다름 |
| 직접 taper | 위와 같은 K·반복 수, 기존 기본값 유지 | 반사 패딩 바깥 부분을 평균으로 감쇠하고 복원 후 원본으로 크롭 |
| FFT 추정 taper | 두 직접 복원이 하나의 추정 PSF 사용 | 방향 또는 길이 후보가 없으면 생략. 정답 PSF 행과 별도 집계 |

scikit-image가 평소 사용하는 Laplacian 정규화 Wiener는 이 수치 일치
검사와 설정이 다르다. RL 비교 역시 경계가 달라 라이브러리 간 순위를
일반화할 수 없다. 복원 엔진은 수정하지 않았다.

## 실험 구성

공개 데이터는 scikit-image의 astronaut, camera, chelsea를 사용한다.
Quick은 길이 15px·각도 30°에서 σ=0, 0.01의 두 조건이다. Full은
L={7,15,25,35}, θ={0,30,60,135}, σ={0,0.005,0.01,0.02}를
원본 해상도에서 전부 적용한다. K와 RL 반복 민감도는 각 σ의
15px·30° 정답 PSF에서만 조사한다. NAFNet은 이미지별
15px·30°·σ=0.01 조건과 공식 참조 없는 흐림 예제에서 비교했다.

보고서 그래프의 품질 평균은 비교 대상 모두의 지표가 있는 공통 조건을
사용한다. NAFNet은 대표 조건에서만 별도 비교한다. 추정 오차 그림의
분모는 전체 합성 조건이며, 오차 평균은 후보를 반환한 조건 기준이다.
참조 없는 예제는 CSV의 품질 값을 비워 두고 정성 비교 이미지로 남긴다.

## 재개

실행 설정은 `run.json`에 기록한다. 입력 파일 SHA-256, 처리 크기,
실험 옵션·시드, 패키지 소스 SHA-256, 라이브러리 버전, 장치 설정 및
선택한 가중치 해시가 달라지면 기존 실행을 재개하지 않는다. 케이스
결과는 임시 디렉터리에서 작성하고 완료 후 원자적으로 게시한다.
완료 메타데이터와 대표 PNG의 해시를 검증한 결과만 재사용한다. 전체
CSV와 그래프는 재개한 결과와 새 결과를 합쳐 다시 생성한다.

## Quick 검증

Linux CPU에서 공개 이미지 세 장을 최대 128px로 축소해 합성 6조건과
참조 없는 공식 흐림 예제 1건을 실행했다. CSV 115행을 생성했고,
동일 설정의 `--resume`은 7조건을 모두 재사용했다. 정답 PSF
Wiener 순환 경계와 scikit-image는 6조건 모두 픽셀 단위로 일치했다.

Quick의 camera 128×128, σ=0, 15px·30°에서 scikit-image RL의
기본 영 경계는 12.76dB/0.4648이었다. 동일 라이브러리에 반사 패딩을
먼저 적용하고 중앙을 크롭한 진단에서는 22.63dB/0.6946이었다.
경계 조건 차이가 점수에 크게 기여하는 사례다. 실험 CSV의 기본
대조군 설정과 복원 알고리즘은 변경하지 않았다.

중단 검증에서는 Quick 실행을 첫 조건 게시 직후 종료했다.
재개 시 그 조건 하나를 재사용하고 나머지 하나를 계산했다. 입력
내용 또는 해상도가 달라진 재개 요청을 거부하는 단위 테스트도
실행했다. 가중치가 없는 실행에서는 NAFNet 행만 생략됐다.

## Full 결과

공개 3장의 원본 크기에서 192조건과 공식 참조 없는 예제 1건을
완료했다. 동일 설정의 전체 재개에서 193조건을 모두 재사용했다.
CSV 1,843행 중 1,785행은 성공, 58행은 추정 PSF 부재로
생략이었다. 일반 처리 실패는 없었다. 순환 경계의 직접 Wiener와
scikit-image Wiener는 **192조건 전부**에서 최대 픽셀 차이가 0이었다.
방향은 188/192조건에서 반환됐고 평균 축 오차는 2.02°였다. 길이는
163/192조건에서 반환됐고 평균 절대 오차는 2.72px였다.

아래는 추정 PSF를 포함한 고전 복원 비교 방법이 모두 완료된
동일한 163조건의 평균이다. 시간은 Linux CPU 단회 관측값이다.

| 직접 Wiener wrap · 정답 | 21.19 | 0.5301 | 11.6 |
| scikit-image Wiener wrap · 정답 | 21.19 | 0.5301 | 19.8 |
| 직접 RL wrap · 정답 | 24.05 | 0.7185 | 263.0 |
| scikit-image RL zero · 정답 | 18.48 | 0.6711 | 525.8 |

| 직접 RL taper · 정답 | 27.13 | 0.7498 | 604.7 |

astronaut의 무잡음 0°·35px 조건에서 길이가 7px로 잘못 추정됐다.
실험 출력의 `largest-length-error.png`에 이 조건의 입력과 정답·추정
복원 패널을 저장했다. RL은 정답 PSF 21.79dB, 추정 PSF 17.92dB였다. 공식 흐림 예제는 원본 크기에서 FFT 후보 30.79°·24px로
직접 Wiener와 RL을 실행하고 NAFNet과 함께 시각적으로 비교했다.
정답 참조가 없어서 세 복원의 PSNR과 SSIM은 계산하지 않았다.

### K 및 반복 횟수

각 행은 15px·30° 조건의 공개 세 장 평균에서 각 지표가 가장 높은
후보를 표시한다. 참조 PSF를 사용했고 경계 방식은 taper다.

| σ | Wiener PSNR 최고 K | Wiener SSIM 최고 K | RL PSNR 최고 반복 | RL SSIM 최고 반복 |
| ---: | ---: | ---: | ---: | ---: |
| 0 | 0.005 | 0.005 | 40 | 40 |
| 0.005 | 0.01 | 0.05 | 40 | 20 |
| 0.01 | 0.02 | 0.05 | 40 | 10 |
| 0.02 | 0.05 | 0.05 | 10 | 5 |

σ=0.02에서 RL 5회는 평균 108ms와 SSIM 0.7087, 40회는
778ms와 SSIM 0.4783이었다. 이 실험 범위에서 잡음과 목표 지표에
따라 좋은 후보가 달랐다. 기존 기본 K와 반복 횟수는 그대로 유지했다.

대표 3조건(15px·30°·σ=0.01)에서 정답 PSF Wiener·RL 및 NAFNet
평균 PSNR은 각각 24.52, 27.23, 28.24dB였고 SSIM은 각각
0.4563, 0.7458, 0.7686이었다. NAFNet CPU 평균 추론 시간은
3.52초였다. 세 조건의 제한된 결과다.

Linux Python 3.11.9에서 pytest 32개와 하위 테스트 18개가 통과했다.
기존 `main.py --analyze-only`와 단일 이미지 `experiment compare`도
실행했다. 사용자 촬영 선명·흐림 원본과 Windows·CUDA 실행은 미검증이다.
